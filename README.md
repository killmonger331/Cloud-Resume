# Cloud Resume Challenge

## Overview

This project is a static webpage displaying work experience, education, skills, and certifications created using AWS.

Technologies used:

- AWS S3
- AWS CloudFront
- AWS Lambda
- API Gateway
- DynamoDB
- IAM
- GitHub
